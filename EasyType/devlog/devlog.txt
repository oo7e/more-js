4. A problem rose when I tried to press space to go to the next word. Basically, long story short, I then created these to make this thing work like intented:
1) words => the list of words you need to write
2) written_word => the list of words you've already written
3) current_word => current word that needs to be written
4) current_written_word => current word that you've written so far.

5) word_counter => which word in the `words` list you're on
6) local_word_index => the index of the `current_written_word`; used to check whether the last input was correct or INcorrect
